# How to cite this code and its scientific sources

The MIT licence gives permission to reuse the software. Citation is a
separate scholarly obligation. Cite this repository and the papers relevant
to the model or tutorial you use.

## Software

Cite this repository as:

> Algar, S. D. (2026). *How Physical Reservoirs Compute:
> Dynamics and Topology — teaching code*, version 0.1.0.
> <https://github.com/ShannonDeeAlgar/swarm-reservoir-tutorials>

If the release is later archived with Zenodo, add the release DOI here.

## Reservoir computing and echo-state networks

- Jaeger, H. (2001). *The “Echo State” Approach to Analysing and Training
  Recurrent Neural Networks*. GMD Report 148.
  <https://doi.org/10.24406/publica-fhg-291111>

## Swarm reservoirs

- Lymburn, T., Algar, S. D., Small, M., & Jüngling, T. (2021). Reservoir

  <https://doi.org/10.1063/5.0039745>
- Mizzi, A., Algar, S. D., Lymburn, T., Walker, D. M., & Small, M.
  *Reservoir Computing with Territorial Agents*. Manuscript supplied with
  the implementation. Update this entry when publication details are available.
- Lund, T., Adams, A., Aubert-Kato, N., & Ikegami, T. (2026). State
  transitions unlock temporal memory in swarm-based reservoir computing.
  *PeerJ Computer Science, 12*, e3763.

Cite the specific paper whose model, benchmark, observation layer or result
you use. Citing this software is not a substitute for those papers.
